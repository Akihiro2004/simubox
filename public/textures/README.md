# Earth sky texture

`earth-blue-marble.webp` is a 1024 × 512 WebP derivative of NASA's Blue Marble land, ocean, ice, and cloud composite.

Source: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57735/land_ocean_ice_cloud_2048.jpg

Credit: NASA Goddard Space Flight Center / Reto Stöckli; NASA Earth Observatory (Blue Marble).
